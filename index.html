Einstellungen

Buchstaben pro Silbe (Mehrfachauswahl)

Verteilung der Silbenlängen: 50 %

Häufigkeit der hinteren Buchstaben: 0 %

0 % = alles zufällig. Je höher der Wert, desto häufiger kommen Silben mit Buchstaben vor, die weiter hinten eingegeben wurden. Bei 100 % steckt der letzte Buchstabe in jeder Silbe.

Sprachausgabe (Vorlesen)

Aussprache-Korrekturen

Wird eine Silbe falsch vorgelesen, lege hier fest, wie sie für die Stimme geschrieben wird, z. B. Silbe „tel“ → „tell“. Eingebaut sind schon: tel, at, ok, ex, hi. Tippe auf einen Eintrag, um ihn anzuhören.
